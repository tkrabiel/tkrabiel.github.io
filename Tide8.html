🌊 How to fetch NOAA tide predictions (step by step)

Learn to use the CO‑OPS API with live examples · San Francisco & Anchorage

📌 Step 1 – Find the station ID

Every NOAA tide station has a 7‑digit ID. You can find it on the NOAA Tides & Currents map.

Example:
🌉 San Francisco = 9414290
❄️ Anchorage = 9455920

🔗 Step 2 – Build the API URL

The base endpoint is https://api.tidesandcurrents.noaa.gov/api/prod/datagetter. You add parameters to specify what you want.

Essential parameters:

  • product=predictions – get tide predictions
  • station=9414290 – station ID
  • begin_date=20250101 & end_date=20250102 – date range (YYYYMMDD)
  • datum=MLLW – reference level (Mean Lower Low Water)
  • units=english or metric
  • interval=hilo – high/low events only, or 6 for 6‑minute data
  • time_zone=gmt – consistent time reference
  • format=json – machine‑readable output
🔍 Example URL (San Francisco, Jan 1–2 2025, high/low): 
https://api.tidesandcurrents.noaa.gov/api/prod/datagetter?product=predictions&station=9414290&begin_date=20250101&end_date=20250102&datum=MLLW&units=english&interval=hilo&time_zone=gmt&format=json

You can use NOAA's URL Builder to experiment.

📡 Step 3 – Fetch the data with JavaScript

Use the fetch() function. Because of browser CORS restrictions, we need a proxy. A simple one is https://corsproxy.io/? + your encoded URL.

const url = 'https://api.tidesandcurrents.noaa.gov/...';
const proxyUrl = 'https://corsproxy.io/?' + encodeURIComponent(url);

fetch(proxyUrl)
  .then(response => response.json())
  .then(data => {
    console.log(data);
    // data.predictions is an array of {t: "2025-01-01 01:23", v: "4.56", type: "H"}
  });

🧪 Step 5 – Real‑world notes

  • CORS Proxy: For production, use a dedicated proxy or server‑side request. The demo uses corsproxy.io (public service).
  • Rate limits: NOAA API has usage limits; don't make excessive calls.
  • Data structure: The predictions array contains objects with t (time), v (value), and type ('H' or 'L') when using interval=hilo.
